# Инициатива бота (Proactive Messaging)

## Общая концепция

Бот сам пишет первым, если пользователь долго молчит. Это не случайные сообщения, а продуманная система с памятью, обратной связью и адаптацией.

---

## 1. Когда бот решает писать

### 1.1 Базовые условия

| Условие | Описание |
|---------|----------|
| silence_threshold | Минимальное время молчания (по умолчанию 180 мин) |
| initiative_probability | Вероятность инициативы (по умолчанию 0.8 = 80%) |
| max_daily_initiatives | Макс. инициатив в день (по умолчанию 5) |
| check_interval_minutes | Как часто проверять (по умолчанию 30 мин) |

### 1.2 Адаптивный порог молчания

Если `adaptive_threshold: true`, бот анализирует историю сообщений пользователя:
- Берет медиану интервалов между сообщениями пользователя
- Порог = медиана * 2
- Ограничен `min_silence_minutes` (30) и `max_silence_minutes` (1440)

Пример: пользователь пишет каждые 2 часа -> порог ~4 часа.

### 1.3 Байесовская вероятность (feedback)

Если `feedback_enabled: true`, вероятность инициативы адаптируется:
- Пользователь ответил -> повышаем (successes +1)
- Не ответил -> понижаем (failures +1)
- Формула: Beta-распределение, ожидание = (successes+1) / (successes+failures+2)
- Результат масштабируется в [min_probability, max_probability]

## 2. Как генерируется сообщение

### 2.1 Типы инициатив

Бот выбирает тип с наименьшей частотой (балансировка):

| Тип | Описание |
|-----|----------|
| question | Вопрос пользователю |
| observation | Наблюдение/замечание |
| continuation | Продолжение предыдущей темы |
| thought | Случайная мысль |

### 2.2 Промпт для LLM

System prompt содержит:
- Персону бота (кто он)
- Правила (не повторять темы, не писать "Привет", и т.д.)
- Эмоциональное состояние (если ignore streak высокий)
- Тип инициативы
- Досье чата (интересы пользователя)

User prompt содержит:
- Последние сообщения из STM
- Историю инициатив (чтобы не повторять)
- Запрещенные темы
- Время молчания
- Инструкцию: "Если решил написать — напиши мысль. Если нет — МОЛЧУ"

### 2.3 Решение LLM

LLM может ответить:
- **Мысль (1-2 предложения)** -> отправляется пользователю
- **МОЛЧУ** -> инициатива отменяется

Если LLM сказал МОЛЧУ — бот не пишет.

## 3. Дедупликация

### 3.1 Проверка перед отправкой

`_is_similar_to_recent()` сравнивает новое сообщение с последними 3 инициативами:
- Извлекает ключевые слова (существительные 4+ символов)
- Считает Jaccard similarity
- Если >= 0.5 -> считает дубликатом, пропускает

### 3.2 Запрещенные темы в промпте

Ключевые слова из последних 5 инициатив добавляются в промпт:
"ЗАПРЕЩЕННЫЕ темы (уже обсуждались, НЕ повторять): ..."

---

## 4. Досье на чат (ChatDossier)

### 4.1 Что хранится

- **interests** — интересы пользователя (IT-ключевые слова приоритетнее)
- **topics** — обсуждавшиеся темы
- **facts_shared** — уже рассказанные факты
- **personality_notes** — наблюдения о пользователе

### 4.2 Как заполняется

Анализируются сообщения пользователя из STM (каждые 5 сообщений):
- Извлекаются существительные
- IT-термины получают приоритет
- Сохраняются топ-15 интересов

### 4.3 Использование

- Передается в промпт LLM: "[ДОСЬЕ ЧАТА] Интересы: python, docker..."
- Если LLM не сгенерировал инициативу — бот ищет факт по топовому интересу
- Факты дедуплицируются (не рассказываем один факт дважды)

---

## 5. Обратная связь и "обида"

### 5.1 Ignore streak

Счетчик проигнорированных инициатив подряд:
- +1 когда пользователь не ответил на инициативу (таймаут multi-turn)
- Сброс когда пользователь ответил

### 5.2 Эмоциональные состояния

| Streak | Состояние |
|--------|-----------|
| 0-2 | Норма |
| 3-4 | Легкая обида |
| 5-6 | Средняя обида (может написать что одиноко) |
| 7-9 | Сильная обида (выражает обиду) |
| 10+ | Глубокая обида (требует внимания, эмоциональные сообщения) |

Эмоциональное состояние добавляется в system prompt.

---

## 6. Multi-turn инициатива

Если `multi_turn_enabled: true`:
- После отправки инициативы бот ждет ответа (30 мин)
- Если ответил -> считает успехом
- Если таймаут -> считает неудачей, streak +1

| Файл | Содержимое |
|------|-----------|
| `data/{context}/proactive_stats.json` | Статистика по дням |

| `data/{context}/initiative_history.json` | История инициатив |
| `data/{context}/ignore_streak.json` | Счетчик игнора |

## 8. Параметры в persona YAML

```yaml
proactive:
  enabled: true
  check_interval_minutes: 30
  silence_threshold_minutes: 180
  initiative_probability: 0.8
  max_daily_initiatives: 5
  
  # Адаптивный порог
  adaptive_threshold: true
  min_silence_minutes: 30
  max_silence_minutes: 1440
  
  # Обратная связь
  feedback_enabled: true
  min_probability: 0.1
  max_probability: 0.9
  
  # Типизация
  type_balance: true
  initiative_history_size: 10
  
  # Multi-turn
  multi_turn_enabled: false
```

    |
    v

## 10. Команды

Нет специальных команд для инициативы. Она работает автоматически.
