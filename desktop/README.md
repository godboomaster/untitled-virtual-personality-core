# Панель Virtual Persona (desktop/)

Значок в трее (строка меню macOS, область уведомлений Windows) и окно-панель
по клику. Панель запускает, перезапускает и останавливает бэкенд бота
(`python -m app.main api`) и веб-интерфейс (`vite` из `web/`), показывает их
состояние, браузеры бота, Ollama, свободную память и живой лог, а ещё умеет
открыть браузер бота видимым, чтобы войти в веб-чаты или пройти капчу.

Цвет значка — состояние бота: зелёный — работает, жёлтый — запускается,
останавливается или не отвечает, красный — упал, серое кольцо — остановлен.

Tauri 2: Rust (`src-tauri/`) + React (`src/`). Окно — системный WebView
(WKWebView / WebView2), своего Chromium нет.

## Что делает

- **Запуск/остановка/перезапуск.** Остановка штатная: `POST /api/system/shutdown`,
  дальше uvicorn гасит сервер и браузер бота, как по Ctrl+C. Если бэкенд не ответил
  за 25 с — SIGTERM, затем SIGKILL (на Windows `taskkill /T /F`).
- **Бот, запущенный в терминале,** панель видит как «запущен вне панели». Его тоже
  можно остановить или перезапустить: после перезапуска он работает уже под панелью.
- **Падение:** причина и последняя строка вывода видны в панели. Автоперезапуск — не
  больше 3 раз за 10 минут, дальше панель ждёт пользователя.
- **Лог** — в `logs/backend-ГГГГ-ММ-ДД.log` и `logs/web-…` в корне проекта, хранится
  14 дней. Опросы самой панели (`/api/health` и др.) в файл не пишутся. В окне — лента
  `/api/logs`, а если бэкенд упал — последние строки вывода процесса с traceback.
- **Браузер бота** — rescue пула H (как реплика «почини браузер»): веб-чаты
  перезапускаются в видимом окне. «Готово» завершает rescue по тому же правилу, что
  реплика «готово».
- **Выход** из панели останавливает то, что запустила она сама; бот из терминала
  продолжает работать.

Параметры бэкенда (порт `API_PORT`, хост `API_HOST`, `API_TOKEN`, `OLLAMA_URL`) панель
читает из `.env` / `.env.config` проекта по тем же правилам, что `app/main.py`.

## Настройки

Шестерёнка в панели. Файл — `config.json` в папке настроек приложения:

- macOS: `~/Library/Application Support/dev.virtualpersona.panel/`
- Windows: `%APPDATA%\dev.virtualpersona.panel\`

Папка проекта по умолчанию — та, из которой собрана панель. Python, если не задан,
ищется сам: `.venv`/`venv` проекта → `PATH` login-shell → обычные места установки. Берётся
первый, где импортируются `fastapi`, `uvicorn` и `dotenv`, и найденный путь запоминается.
Node.js нужен для веб-интерфейса, его в `web/` запускают напрямую
(`node web/node_modules/vite/bin/vite.js`) — сначала выполните `npm ci` в `web/`.

## Сборка

Нужны Node.js и Rust (`rustup`). Проверка интерфейса и Rust-тесты:

```bash
cd desktop
npm ci
npm run build                       # tsc + vite
(cd src-tauri && cargo test)        # в т.ч. жизненный цикл на поддельном бэкенде
```

### macOS

```bash
npm run tauri dev                   # разработка: окно с горячей перезагрузкой
npm run tauri build -- --bundles app,dmg
```

Готовое приложение: `src-tauri/target/release/bundle/macos/Virtual Persona.app`.
Перенесите его в «Программы» **до** того, как включать «Открывать панель при входе»:
агент автозапуска запоминает путь к приложению.

Бот, запущенный панелью, работает от её имени. Поэтому macOS один раз спросит
разрешения, которые раньше давались терминалу: управление другими приложениями
(AppleScript), а позже — микрофон.

### Windows

Нужны Rust с MSVC (`rustup default stable-msvc`), Visual Studio Build Tools
(«Разработка классических приложений на C++») и WebView2 (в Windows 11 он уже есть).

```powershell
cd desktop
npm ci
npm run tauri build -- --bundles nsis
```

Установщик: `src-tauri\target\release\bundle\nsis\Virtual Persona_0.1.0_x64-setup.exe`
(ставится для текущего пользователя, без прав администратора). Бэкенд и vite
запускаются без окон консоли. Python ищется так же: `.venv\Scripts\python.exe`,
затем `PATH` (заглушка Microsoft Store пропускается), затем
`%LOCALAPPDATA%\Programs\Python\Python3*`.

## Устройство

| Файл | Что внутри |
|---|---|
| `src-tauri/src/main.rs` | сборка приложения: плагины, трей, окно, команды |
| `src-tauri/src/supervisor.rs` | процессы бэкенда и vite: запуск, остановка, падения, «внешний» процесс |
| `src-tauri/src/platform.rs` | различия ОС: группы процессов / taskkill, PID по порту, поиск Python и Node |
| `src-tauri/src/probe.rs` | проверки: `/api/health`, порты, CDP браузеров, Ollama, память |
| `src-tauri/src/logs.rs` | вывод процессов → файлы `logs/` и хвост для панели |
| `src-tauri/src/commands.rs` | команды окна: снимок состояния, действия, настройки |
| `src-tauri/src/tray.rs`, `panel.rs` | значок и меню трея; окно у значка, прячется при потере фокуса |
| `src/` | интерфейс панели (React) |

Эндпоинты бэкенда для панели — в `app/api/server.py` (раздел «Панель на рабочем
столе»), тест — `scripts/test_desktop_api.py`.
