# Бу объясняет — 01. Что такое Virtual Persona Core?

Первый ролик знакомства: **1:12, 1920×1080, 30 кадров/с**, русская озвучка,
встроенные субтитры. Главный герой — дружелюбный призрак Бу с сиреневым платком.

Готовое видео: [output/virtual-persona-core-01.mp4](output/virtual-persona-core-01.mp4).
Обложка: [output/poster.jpg](output/poster.jpg).
Раскадровка: [output/storyboard.jpg](output/storyboard.jpg).
Отдельные субтитры: [output/intro.ru.srt](output/intro.ru.srt).

## Что показано

1. Бу знакомится со зрителем и представляет проект.
2. Персонажу выбирают характер, манеру общения и умения.
3. Обычный разговор и пример сохранённого факта.
4. Напоминания, заметки, помощь с учёбой.
5. Настроение, история и сообщения по инициативе персонажа.
6. Браузер, Telegram, приложение Android; текст и голос.
7. Для начала нужны персонаж и подключённая модель.
8. Анонс следующего ролика: первый запуск и первый разговор.

Содержание сверено с `README.ru.md` проекта и `web/src/components/StartGuide.tsx`.
Карточки и переписка — иллюстрации возможностей, а не запись интерфейса.
Персональные данные, реальные переписки, API-ключи и запущенное ядро не используются.

## Как пересобрать

Нужны Python 3.11+, Pillow, NumPy и FFmpeg. Озвучка уже включена в `audio/`,
поэтому пересборка не требует сети, ключей или доступа к синтезатору речи.

```bash
cd media/explainers/episode-01
python3 -m pip install -r requirements-video.txt
python3 build.py --preview   # музыка, субтитры, обложка, кадры и раскадровка
python3 build.py             # всё перечисленное и финальный MP4
```

На macOS используется Avenir Next, на Linux — DejaVu Sans. При замене шрифта
проверьте раскадровку, поскольку размеры текста могут измениться.

## Как изменить ролик

- `script.json` — реплики, текст субтитров, голос и темп речи.
  Поле `say` допускает фонетическое написание иностранных слов;
  `caption` содержит их обычное написание.
- `synthesize.py` — локальная озвучка системным голосом **Milena** через `say`
  на macOS. После изменения реплики удалите соответствующий WAV из `audio/`
  и запустите `python3 synthesize.py`. Уже существующие WAV переиспользуются.
  Синтезатору нужен доступ к системной службе речи; в ограниченной песочнице
  он может записывать пустые файлы, что скрипт обнаруживает.
- `build.py` — персонаж, графика, движения, монтаж, музыка и экспорт.
  `ghost()` рисует Бу кривыми и примитивами; `art()` задаёт содержание сцен.
  Движение рта следует громкости настоящей звуковой дорожки.
  `synth_audio()` создаёт тихую оригинальную мелодию и звуки переходов.

Длительности сцен рассчитываются по реальным аудиофайлам. Субтитры,
анимация и озвучка используют одну временную шкалу. Таблица времени
сохраняется в `output/timing.json`.

Графика и музыка целиком созданы кодом, без стоковых материалов и генерации
изображений. Русская речь синтезирована системным голосом.

## Проверка готового файла

```bash
ffprobe -v error -show_streams -show_format output/virtual-persona-core-01.mp4
ffmpeg -v error -i output/virtual-persona-core-01.mp4 -f null -
```

Экспорт: H.264, `yuv420p`, AAC stereo, контейнер MP4 с `faststart`.
Субтитры встроены в изображение, поэтому видны в любом видеоплеере.
