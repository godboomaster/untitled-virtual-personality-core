Дата: 2026-07-29. Ветка: `test-bot`. Код со всеми фиксами: RAG из
arrodes-big-update, per_query 3x, small-to-big, аспектный сплит, RRF-слияние,
rescue с якорем на сцену, промпт с ГЛАВНЫМ ПРАВИЛОМ и дизамбигуациями.

|---|---|---|---|---|
| vol1_r1 | 11.3s | 10.8s | 16.8s | 19.4s |

| vol1_r5 | 14.8s | 12.9s | 27.4s | 43.7s |
| vol2_r1 | 13.9s | 10.5s | 27.2s | 46.0s |
| vol2_r2 | 10.8s | 10.2s | 15.1s | 17.9s |

**Среднее ~13.5s на запрос, p95 до ~27s.** Цена новых механизм: 3 Ollama-вызова
(перевод, дистилляция, аспектный сплит), векторный поиск ×~9 вариантов запроса
(per_query=300), BM25 ×~5, rerank cross-encoder по ~110 кандидатам × до 8
запросов (основной + дистиллят + 3 алиаса + 2 аспекта), rescue-поиски,
small-to-big. Для прода это ощутимо: если latency критична, кандидаты на
оптимизацию — кэш перевода/дистиллята, rerank по max только для 2-3 вариантов,
ограничение rescue-поисков, таймауты Ollama (сейчас 5s ×3).
