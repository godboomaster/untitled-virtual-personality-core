# Отчёт: ретест анти-галлюцинационных фиксов (20 проблемных вопросов)

Дата: 2026-07-29. Ветка: `test-bot`.

## Фиксы

1. Промпт — правило РЕКВИЗИТ СЦЕН: числа/имена/предметы/исходы — только
   дословно из фрагментов; нет детали — пропуск, не достраивание.
2. Промпт — правило ВРЕМЯ: не переносить события поздних фрагментов на ранние
   сцены; при противоречии — опора на ближние к вопросу.
3. Промпт — справочник с фолбэком: персонажа нет в справочнике → искать путь
   во фрагментах книги; «не знаю» — только если нет ни там, ни там.
4. `book_context.py` — предупреждение в заголовке, если фрагменты из разных
   томов («разные периоды истории»).

доработку (либо хроно/тематический фильтр выдачи, либо ещё одно правило
