# Темы оформления (скины)

Скин — обёртка над обычным интерфейсом: свои цвета, шрифты, фактуры, формы и
мелкий декор поверх **тех же** разделов, кнопок и полей. Включается в разделе
«Скины» на всё приложение или только для одной персоны (её чат, досье, комната).
Одна и та же сборка — и в браузере на компьютере, и в APK (узкий экран — `mobile.css`,
`@media (max-width: 760px)`).

> Не путать с `web/src/skins/` — это старый движок HTML-скинов персон в iframe.

## Устройство

```
web/skins/
  index.ts        реестр: всё из папок подхватывается само (import.meta.glob)
  types.ts        SkinManifest, SkinAmbientProps
  <id>/
    manifest.ts   название, строка-описание, схемы ['light'] | ['dark'] | ['light','dark'] (первая — по умолчанию)
    swatch.css    миниатюра в галерее + `@import './fonts.css';` первой строкой — грузится сразу
    skin.css      сама тема — грузится, когда скин впервые включили
    fonts.css     @font-face (пишет fetch_font.py), fonts/*.woff2 — локальные копии
    ambient.tsx   необязательно: живой фон (React, default export)
```

Хозяин темы — `src/components/SkinHost.tsx`: ставит на `<html>` атрибуты
`data-skin="<id>"` и `data-theme="light|dark"`, когда CSS уже загружен.
Выбор — `src/skinTheme.ts` (localStorage устройства). Если у скина одна схема,
переключатель LIGHT/DARK в шапке её не меняет.

## Правила CSS

- **Каждый** селектор `skin.css` начинается с `html[data-skin='<id>']`; вариант
  схемы — `html[data-skin='<id>'][data-theme='dark']`. Никаких голых `body`,
  `button`, `span`, `*` без этого префикса.
- Начинать с токенов — переменных `:root` из `src/index.css` (их ~25: `--bg`,
  `--bg-panel`, `--bg-panel-2`, `--text`, `--text-dim`, `--text-muted`, `--border`,
  `--border-soft`, `--accent`, `--accent-dim`, `--accent-soft`, `--bg-hover`,
  `--border-accent`, `--accent-dark`, `--danger`, `--success`, `--warning`,
  `--term-bg/-line/-dim/-bright`, `--topbar-bg`, `--overlay-bg`, `--radius-sm`,
  `--radius`, `--shadow-card`, `--shadow-card-hover`, `--font`, `--font-disp`,
  `--font-mono`). Это перекрашивает большую часть сразу; дальше — компоненты.
- В `index.css` есть жёсткие цвета (`#ffffff` на hover у primary/chip/danger и
  т. п., ~80 мест) — найти `grep -n "#[0-9a-fA-F]\{3,6\}" src/index.css` и
  перекрыть там, где это видно.
- Миниатюра: только в `swatch.css`, селектор `.skin-swatch[data-swatch='<id>']`
  (+ `[data-scheme='dark']`). Переменные приложения там **не** использовать —
  их перекрашивает включённый скин; свои — `--sw-bg`, `--sw-panel`, `--sw-side`,
  `--sw-text`, `--sw-dim`, `--sw-in`, `--sw-out`, `--sw-line`, `--sw-accent`,
  плюс любые свои свойства. Разметка — `SkinSwatch` в
  `src/components/SkinThemeGallery.tsx`.
- `skin.css` не трогает `.skin-swatch` и её детей.

## Обязательно

1. **Только обёртка.** Ни одна кнопка, поле, вкладка, переключатель, пункт меню,
   статус не прячется, не перекрывается, не уезжает за экран и не становится
   некликабельной. Не менять порядок и состав; `display:none` — только для
   чисто декоративного (`.corner`, глитч-копии заголовка). Декоративные
   псевдоэлементы — `pointer-events: none` и не поверх полей ввода.
   Отступы, радиусы, рамки, высоты — можно, если раскладка не ломается на 1440 и на 390.
2. **Без эмодзи, без картинок-иллюстраций, без персонажей.** Нельзя: SVG/растровые
   рисунки предметов (листья, луны, облака-картинки, звёзды-рисунки, замки),
   фото. Можно: градиенты, рамки, тени, маски, `clip-path` с геометрией
   (ромб, четырёхлучевая искра как фигура), процедурная фактура через
   data-URI SVG с `feTurbulence` (шум бумаги, зерно), повторяющиеся
   CSS-узоры (сетки, растр, штриховки).
3. **Читаемость.** Основной текст — хорошо читаемый шрифт (гротеск или
   книжная антиква), не меньше 13–14px. Декоративные, рукописные, пиксельные
   шрифты — только заголовки, логотип, подписи разделов, крупные цифры.
   Все шрифты — **с кириллицей** (интерфейс русский). Контраст основного текста —
   не ниже 4.5:1, подписей — не ниже 3:1, в обеих схемах.
4. **Ничего резко не мигает.** Никаких стробов, быстрых миганий,
   вспышек яркости. Фоновые анимации — медленные (период от ~4 с), мягкие.
   Глитч — редкий (раз в 8+ с), короткий, малой амплитуды, без вспышек.
   При `prefers-reduced-motion` всё стоит (index.css уже глушит animation и
   transition; `ambient.tsx` получает `reducedMotion` и рисует статичный кадр).
5. **Телефон.** Проверять 390px: меню-шторка (`.sidebar--open`,
   `.sidebar-backdrop`), чат, досье, модалки. `backdrop-filter` — экономно
   (не больше 2–3 крупных размытых поверхностей, blur ≤ 16px): APK — это
   Android WebView на телефоне среднего класса. Анимировать только
   `transform`/`opacity`. Отступы системных панелей — `--sa-top/-bottom/-left/-right`
   (не ломать их).
6. **Шрифты локально.** Через `fetch_font.py` (латиница + кириллица), не больше
   ~400 КБ на скин. Ссылок на внешние CDN нет — APK бывает без интернета.

## Живой фон (ambient.tsx)

```tsx
import type { SkinAmbientProps } from '../types';
export default function Ambient({ scheme, reducedMotion }: SkinAmbientProps) { … }
```

Рисуется в `.skin-ambient` (`position: fixed; inset: 0; z-index: 0;
pointer-events: none`) под `#root` (z-index 1). Видно его там, где интерфейс
прозрачный или полупрозрачный (`.content` без фона, фон страницы — `body`).
Canvas или DOM; частиц ≤ ~80, devicePixelRatio ≤ 2, пауза при `document.hidden`,
`requestAnimationFrame` с ограничением ~30 кадров/с, при `reducedMotion` — один
статичный кадр. Никаких фигур-рисунков — только точки, свечения, полосы, шум.

## Что покрыть (чек-лист)

Фон страницы · сайдбар (логотип, пункты, `.nav-indicator`, подвал, кнопка
сворачивания) · шапка `.topbar` (заголовок, `.theme-toggle`, статус) ·
`.section-header/-title/-subtitle` · `.card`, `.card-title` · кнопки `.btn`
(`--primary`, `--ghost`, `--chip`, `--danger`, `--icon`, hover/active/disabled) ·
поля `.input`, textarea, `.select-trigger` и выпадающее меню Select, чекбоксы,
переключатели, ползунки · `.tabs/.tab` · `.badge`, `.dot`, `.status-led` ·
`.avatar` · чат: список персон, шапка, пузыри (свои/персоны), время, поле
ввода и отправка, «печатает», цитата ответа, картинки, контекстная панель
справа · страница всех чатов `.chat-card` · досье (модалка, вкладки, счётчики,
списки) · модалки FormModal и диалоги DialogHost, `--overlay-bg` · подсказки
InfoButton · главная (виджеты, календарь, заметки, терминал `--term-*`) ·
«Старт» · комната (рамка сцены, телеметрия, инвентарь) · персоны ·
сервисы · настройки · экран запуска `.boot`/`.boot-panel` · скроллбары,
`::selection`, `:focus-visible` · галерея тем в «Скинах» (`.skin-theme-card`).

Монохромный HUD-декор основы (`.corner`, глитч `.home-title.glitch::before/after`,
моноширинные капс-подписи) — переосмыслить под скин или спрятать декоративное.
