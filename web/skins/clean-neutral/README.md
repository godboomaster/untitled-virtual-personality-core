# Clean Neutral — «Чистый нейтральный»

Тема по умолчанию: тихий дорогой бланк. Кремовые карточки с крупным радиусом
и многослойной мягкой тенью лежат на тёплой бумаге с едва заметным зерном;
слева — тёмно-оливковая колонка меню. Ничего не спорит с артами персонажей:
цвет — только в акцентах, пастель — только в статусах. Схема одна — светлая.

**Палитра.** Бумага `#F3F0E8`, карточки `#FBFAF6` / `#F6F3EC`, текст `#2D2E29` /
`#55564D`, песок `#E6DAC8` `#CBB9A4` `#A48D78` (подписи `#7E6A57`), олива
`#4F5844` → `#434B39`, шалфей `#5E7449` / `#7A9C57` / `#E3E9D6`. Пастель статусов:
голубой `#D0E1E8`, масло `#FBF1D3`, роза `#EFE0E0`. Опасное — `#A4544B`.

**Шрифты** (fonts/, ~260 КБ): Cormorant Garamond 500/600 + курсив 500 как
`CN Serif` — заголовки, имена, крупные цифры, цитаты; Jost 400–600 как `CN Sans` —
текст, кнопки, подписи капсом с разрядкой. Код и YAML — системный моноширинный.

**Фирменные детали.**
- Активный пункт меню — кремовая таблетка с шалфейной точкой, плавно переезжает.
- Реплики персоны — кремовые пузыри с тонкой шалфейной цитатной чертой слева;
  свои — оливковые. Поле ввода — плавающая капсула с мягким кольцом фокуса.
- Вкладки и переключатели — сегмент-таблетки на вдавленной дорожке.
- Заголовки разделов — антиква и линейка с коротким шалфейным отрезком.
- Герой главной и экран запуска — пастельная «утренняя дымка» (очень медленно).
- Терминалы, YAML, демо-окна — оливковые карточки вместо чёрных.

Всё в `skin.css` (блоки подписаны), миниатюра — `swatch.css`. Живого фона нет.
