# Киберпанк (`cyberpunk`)

Интерфейс нетраннера из Найт-Сити по мотивам постеров Edgerunners: почти чёрный
с фиолетово-индиговым подтоном, два неоновых полюса — горячий розовый (ты,
действие) и бирюза (персона, система), лаванда — вторичный тон. Схема одна — тёмная.

**Палитра:** фон `#07040d` / `#0a0712`, панели `#120c1f` · `#181029`, линии `#3a2861` ·
`#5b3f92`, розовый `#ff2e88` (светлый для текста `#ff8ac4`), маджента `#e258b7`,
бирюза `#31d6e0`, мята `#8febdc`, лаванда `#ac9acc`, глубокий фиолетовый `#3b2762`,
индиго `#033d53`, слива `#31142b`, тёмный текст на неоне `#12061a`, опасность `#ff4b5c`.

**Шрифты** (локально, латиница + кириллица, ~260 КБ): Tektur → `CP Display`
(заголовки, имена, крупные цифры), Victor Mono → `CP Mono` (меню, подписи, кнопки,
поля), Exo 2 → `CP Text` (текст сообщений и описаний).

**Фирменные детали:**
- пластины со срезанными углами и неоновой кромкой: форма рисуется в `::before`
  (z-index −1), поэтому ничего внутри не обрезается; розовая метка на нижней кромке;
- штрихкоды и служебные коды: под логотипом, у заголовков разделов, на карточках,
  над показателем hero; вертикальная надпись `NETRUNNER // VPC-2077` у меню;
  номера пунктов меню `01…08`; плашки `NC-NET // UPLINK`, `UPLINK // TX`;
- чат как канал связи: пузыри персоны — бирюзовый `RX`, свои — розовый `TX`
  с зеркальными срезами;
- активный пункт меню — розовая пластина с бирюзовой кромкой и штрихкодом;
- хроматический сдвиг заголовков; у крупного заголовка (главная, «Старт», запуск)
  редкий мягкий глитч: раз в 11–13 с, ~0,2 с, сдвиг ≤ 4 px, только `transform`;
- сканлайны поверх экрана (статичные), растр точек и неоновые засветки фона.

**Живой фон** (`ambient.tsx`): медленный неоновый дождь (≤ 64 штриха, 30 кадров/с)
и широкая мягкая полоса развёртки (проход 18 с); пауза в фоне, при
`prefers-reduced-motion` — один статичный кадр.

**Файлы:** `skin.css` — тема (токены → фон → меню → шапка → пластины → кнопки/поля →
чат → экраны), `swatch.css` — миниатюра, `fonts.css` + `fonts/` — шрифты.
