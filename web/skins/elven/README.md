# Эльфийская сказка (`elven`) — Elven Tale

**Концепция.** Печатная книжка-сказка / постер ар-нуво, строго плоско: кремовый лист, тёмно-лесные
плашки с кремовым текстом, бронзовые линии и бусинные рамки. Ни теней с размытием, ни плавных
градиентов: градиенты с жёсткими стопами только рисуют бусины и линейки. Схемы: `light` (по умолчанию) —
кремовый лист; `dark` — ночная чаща, «свет» передан цветом (мята, крем), а не ореолом.

**Палитра.** Светлая: лист `#eee4c8`, светлый лист `#f8f2df`, глубже `#e6dab8`, лес/чернила `#1d2b22`,
мох `#3a543b`, шалфей `#7d8956`, бронза `#9a7b3c` (текст `#73581d`), персик `#e5a177` (редко).
Тёмная: чаща `#162821`, панели `#1c3129` / плашки `#223b2f`, крем `#ece3c8` / `#e9d3a2`, шалфей `#a5b778`,
мята `#d1f2e0` (активное), персик `#e5a177`.

**Шрифты** (`fonts/`, ≈320 КБ, латиница + кириллица): Great Vibes → `EL Script` (только крупное: логотип,
hero, экран запуска, «Все чаты»); Playfair Display 700/800 → `EL Head` (заголовки разделов, карточек, имена,
цифры); Alegreya Sans 400/500/700 → `EL Text` (весь текст, подписи капителью). Код и журналы — системный моноширинный.

**Фирменное.** Рельс — двойная линия с рядом бусин и ступенчатыми выступами на концах (край меню,
разделитель на главной). Плашки hero и экрана запуска — рельс-рамка с квадратными узлами в углах и
двумя четырёхлучевыми искрами. Форма листа (два угла скруглены, два острых) — карточки, кнопки, поля;
реплики — зеркальные листья: персона — лесная плашка с внутренней линией, вы — светлый лист в чернильной
рамке. Активное — лесная плашка (в тёмной мятная) с бусиной; индикаторы — линзы-листочки; прогресс
(запуск, «Старт», «печатает») — ряды бусин; вторичные кнопки — бусинная (точечная) рамка.

**Файлы.** `skin.css` — токены → узоры → «плашки» (свои токены внутри) → каркас → разделы → телефон;
`swatch.css` — миниатюра; `ambient.tsx` — только в тёмной: до 36 крошечных чётких точек мяты и крема,
медленно всплывают, без ореолов; в светлой фон неподвижен.
