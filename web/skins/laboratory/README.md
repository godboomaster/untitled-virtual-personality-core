# Laboratory — «лаборатория линии»

Тетрадь лаборанта в эстетике чёрно-белой манги: белый картон и чернила, серый
растр-скринтон, рамки панелей, акриловые ярлыки с бликом на цепочке-шариках,
этикетки образцов и штампы. Светлая схема (основная) — лист; тёмная — негатив:
чёрный лист, белые линии и растр.

**Палитра.** Светлая: стол `#ebe9e4`, бумага `#fcfbf8` / `#f3f1ec`, чернила `#151515`,
графит `#53514c`, подписи `#706e69`, линии `#bdbab3`, серебро `#c3c3c1`.
Тёмная: стол `#0b0b0b`, лист `#141413` / `#1a1a19`, «чернила» `#f0ede6`,
графит `#b2afa8`, подписи `#8f8c85`, линии `#48463f`.

**Шрифты** (локально, латиница + кириллица, ~370 КБ): Oswald → `LAB Display`
(заголовки, кнопки), Golos Text → `LAB Text` (основной текст), PT Mono → `LAB Mono`
(подписи, время), Caveat → `LAB Hand` (только логотип и приветствие).

**Фирменные детали.**
- Активный пункт меню — акриловый ярлык с отверстием, висит на цепочке-шариках;
  по акрилу раз в ~10 с проходит мягкий блик.
- Экран запуска — карточка «на цепочке» с серебряным кольцом и растром снизу.
- Чат: реплики персоны — баллоны манги с хвостиком, свои — чёрные «подписи-рамки».
- Карточки — панели манги с растровой тенью, заголовки нумеруются `No.01…`.
- Шапка с фестонной кромкой, разделители — перфорация, подзаголовки — перевёрнутые
  плашки, линейки с делениями под заголовками, линии концентрации в hero.
- Модалки — лист на скотче поверх растровой подложки.

Всё в `skin.css` (токены → основа → сайдбар → шапка → разделы → кнопки → поля →
модалки → чат → страницы → телефон). Миниатюра — `swatch.css`. Живого фона нет:
печатный лист статичен, движение — только блик ярлыка и дыхание индикаторов.
