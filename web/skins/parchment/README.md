# Пергамент и чернила (`parchment`)

Интерфейс свёрстан как страница старопечатной книги (инкунабулы), а не нарисован
«под старину»: плоский тёплый лист, кожаный переплёт, типографика и рубрикация.
Без теней, градиентов-заливок, бликов и пятен; линии 1 и 2 px, углы прямые.
Схема одна — светлая (`['light']`), живого фона нет.

**Палитра.** Лист `#eee4cd`, чистый лист (поля, карточки) `#f5efe2`, вклейка
(свои реплики, выбор) `#e4d6ba` · чернила `#291912`, `#4d3322` · кожа `#74553f` ·
Worn Tan `#997960` и бледная линейка `#cfbd9b` · золото тиснения `#b89a62` / `#dcc28a`
(только на коже) · киноварь `#9a3b26` — рубрика, редко · ярь-медянка `#56622f` — «в сети».

**Шрифты** (локально, ~310 КБ): `PA Text` — Literata 400–700 + курсив (текст,
капитель с разрядкой в подписях, курсивные маргиналии); `PA Display` — EB Garamond
400–700 + курсив, только latin + cyrillic (заголовки, имена, цифры, римские номера).
Код — системный моноширинный.

**Фирменные детали.**
- Переплёт: плоская кожа с двойной золотой рамкой-тиснением; активный пункт —
  киноварная корешковая наклейка с золотой линией; у пунктов — римские номера глав.
- Чат как рукопись: реплика персоны — абзац с линейкой, на поле киноварный пилкроу ¶
  и время маргиналией; своя реплика — вклеенная записка другой бумаги.
- Сургучные печати с неровным краем (`clip-path`): логотип, аватары (кожа),
  выбранная персона, экран запуска, выбранная тема — киноварью.
- Заголовки Garamond с киноварной буквицей; линейка «толстая + тонкая» под разделами;
  титульные листы (главная, «Старт», запуск, окна) — в двойной рамке; таблицы —
  книжные (толстая линейка сверху, тонкая снизу); разделитель — «* * *».

**Что где.** `skin.css` — токены и компоненты по разделам (комментарии в файле);
`swatch.css` — миниатюра галереи.
