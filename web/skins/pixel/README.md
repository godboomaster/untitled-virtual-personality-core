# Pixel Art (`pixel`)

Интерфейс как меню 16-битной RPG: всё — окна с пиксельной рамкой (углы вырезаны ступенькой, жёсткая тень без размытия), выбранный пункт отмечен курсором ▶, кнопки «вдавливаются» на 2 px, прогресс — полоски HP/EXP, аватары — слоты инвентаря.

**Схемы.** Светлая «день на равнине» (основная) и тёмная «ночное подземелье»: индиго-окна со ступенчатым градиентом и кремовой каймой, как в классических JRPG.

**Палитра.** Светлая: фон `#f2dcbd`, окна `#fff5dc` / `#f8e7c5`, контур `#2d2a32`, акцент малиновый `#c42f4f`, выделение `#ffe7a3`, свои реплики `#f2dc9b`, тень заголовков `#f2b66d`. Тёмная: фон `#1b1626`, окна `#2a2340` (полосы `#332a58 → #272042`), кайма `#eadcbe`, акцент золото `#f5c451`, свои реплики `#5a2f55`, тень заголовков `#b8294a`. Шкалы и искры — «зелья»: `#e0475f` HP, `#e9a83a` EXP, `#4f9a55` энергия, `#3f8fd0` загрузка, `#52e2f2`, `#9dcb80`, `#f26b5e`.

**Шрифты** (локально, ~170 КБ): Press Start 2P → `PX Arcade` (логотип, большие заголовки, цифры), Tiny5 → `PX Tiny` (меню, кнопки, вкладки, подписи), Rubik → `PX Text` (весь читаемый текст), JetBrains Mono → `PX Mono` (YAML, код, терминалы). Pixelify Sans проверялся и отброшен: его кириллическая «С» читается как «О».

**Фирменные детали.**
- Курсор ▶ ступеньками (`clip-path`) — у активного пункта меню, собеседника, выбранной темы, пункта Select, стрелок раскрытия; мягко покачивается.
- Реплики персоны — окно диалога JRPG с двойной обводкой; последняя ждёт ответа со значком ▼.
- Дизеринг: затемнение под окнами — шахматка (как полупрозрачность на старых консолях), черты под заголовками, низ шапки, дорожка скроллбара.
- Полоска загрузки ядра — HP, прогресс обучения — EXP с сегментами и бликом, энергия в комнате — зелёная шкала.
- Индикаторы — пиксельные «самоцветы», логотип — кристалл сохранения.
- `ambient.tsx`: медленно всплывающие пиксельные искры (днём пыльца, ночью светлячки с крестиком-ореолом), ≤64 штуки, 30 кадров/с.

**Файлы.** `skin.css` — токены обеих схем, затем блоки по разделам (каркас, кнопки, поля, чат, главная, «Старт», комната, персоны, галерея, мобильный); `swatch.css` — миниатюра; `fonts.css` + `fonts/` — шрифты.
