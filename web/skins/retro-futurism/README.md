# Retro-Futurism — «Ретрофутуризм»

Пульт звездолёта 70–80-х и киноафиша научной фантастики: тёплая аналоговая
ретро-космическая эстетика (не неон киберпанка и не холодное стекло HUD).
Схемы: `dark` (основная, глубокий космос) и `light` (кремовая бумага постера).

**Палитра.** Navy/gunmetal `#0f1820` `#172531` `#1d313c`, оранжевый `#f6723a`,
бирюза `#50a3ab` (мятная `#6fd6c2`), крем `#fadac1`, золото `#f2b950`,
гранат `#c43b39` / `#753130`. Светлая: фон `#f4d9bf`, панели `#fdeedd`, текст `#182b36`.

**Шрифты** (локально, латиница + кириллица, ~150 КБ): Russo One → `RF Display`
(заголовки, кнопки), Rubik → `RF Sans` (текст), Martian Mono → `RF Mono` (приборные подписи).

**Фирменные детали.**
- Hero главной/«Старта» и панель запуска — navy-постер в толстой кремовой рамке
  (в обеих схемах), закатные концентрические кольца в углу, две эллиптические
  орбиты и «спутник», медленно идущий по орбите (70 с на оборот).
- Крупные заголовки — полосатые буквы с прорезями (`background-clip: text`),
  как на постере 1975.
- Под заголовками разделов — четырёхполосная закатная лента (золото/оранжевый/гранат/бирюза);
  тройная метка-«брусок» у заголовков карточек и шапки.
- Сайдбар — колонка пульта (navy всегда) с четырьмя полосами по краю; активный
  пункт — объёмная оранжевая «таблетка» с хвостом из трёх полос.
- Кнопки — «приборные клавиши» с нижней гранью и вдавливанием; аватары — круглые
  иллюминаторы с двойным кольцом; лампочки статуса — круглые, мягко «дышат».
- Лента чата — выпуклый экран-кинескоп: сканлайны, виньетка, свечение;
  терминалы и YAML — янтарный люминофор.
- Зерно постера (`feTurbulence`) на фоне и панелях.

**Файлы.** `skin.css` — тема (блоки подписаны), `swatch.css` — миниатюра,
`ambient.tsx` — звёздная пыль и боке-искры (≤30 fps, пауза при скрытой
вкладке, статичный кадр при reduced motion), `fonts.css` + `fonts/`.
