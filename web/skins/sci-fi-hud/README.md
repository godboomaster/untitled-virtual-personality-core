# Чистый HUD (`sci-fi-hud`)

Интерфейс как техническая графика: тихая, точная приборная панель из хорошего фильма.
Одна система — плоская полупрозрачная заливка («стекло» без размытия: сквозь панели видна
сетка) + волосяная линия 1px + угловые засечки 2px. Ни теней, ни свечений, ни плавных
градиентов: градиенты здесь только рисуют линии, засечки и шкалы (жёсткие стопы).

- **Схемы:** тёмная (по умолчанию) — ночной прибор; светлая — технический лист.
- **Тёмная:** фон Midnight `#08141B`, панели Elite Teal `#132F37` с альфой, линии `#2A4F58` / `#51727A`,
  текст White Sea `#D7E6EA`, `#A6C0C6`, `#7B99A0`; акцент Arctic `#3ED7C1`; своя реплика — Cyber Teal `#1A6D73`.
- **Светлая:** фон Polar White `#F5F5FA`, панели белые с альфой, линии `#C2CED9` / `#8DA2B4`,
  текст и засечки Cobalt `#122F4C`; акцент Cyber Teal `#1A6D73`; своя реплика — кобальт.
- **Шрифты (~226 КБ, `fonts/`):** Jura — заголовки, пункты меню, крупные цифры; IBM Plex Sans —
  текст; IBM Plex Mono — метки, время, бейджи, кнопки.

Фирменные детали:
- **Координатная сетка 96 px с метками совмещения «+»** на фоне (одна фактура скина, SVG data-URI).
- **Засечки панелей** — фон из 8 слоёв `linear-gradient(c, c)` (`--bk`, `--bk1` — левый верхний угол,
  у карточек чатов и персон он в цвете персоны; `--bl` — длина плеча).
- **Рамка-прицел** у активного пункта меню и выбранного собеседника + выноска-лидер до рейки
  делений на правом краю сайдбара (`.nav-indicator::before/::after`, `.sidebar::after`).
- **Реплики-выноски:** у пузыря персоны — засечки и линия-лидер с узлом слева, своя реплика —
  плотный блок цвета с лидером справа.
- **Шкалы-линейки** под заголовками разделов, в прогрессе «Старта» и в ползунке; подпись над
  hero — размерная линия `|——|`; ghost-кнопки — квадратные скобки `[ … ]`.
- **Лимб прибора** справа в hero главной/«Старта» (≥1360 px): кольцо делений, оборот за 2 мин.

Файлы: `skin.css` — токены → фон → панель-примитив → каркас → компоненты → разделы → телефон;
`swatch.css` — миниатюра; `ambient.tsx` нет (живой фон этой теме не нужен). `backdrop-filter` не используется.
