# Волшебное небо (sky-magic)

**Идея.** Плоская иллюстрация неба, как в книжке с картинками: весь экран — небо
(днём перивинкль, ночью тёмно-синий) с редкими звёздами, панели — облака: сплошная
заливка и контур 1,5 px. Внизу сайдбара, героя главной, поля ввода чата и экрана
запуска лежит **облачный берег** — два слоя куполов с контуром, нарисованных
radial-gradient с жёстким краем. Никаких теней с размытием, плавных градиентов и стекла.

**Палитра.** Ночь: небо `#1c2850`, облако-панель `#2b3966` / `#364676`, дальние облака
`#4f6390`, контур `#8ea5cc`, текст и сплошные капсулы `#f1e7d0`, искры `#e9a35b`,
«колодцы» полей `#151e40`. День: небо `#8f9ce0`, облако `#f7efdc` / `#ede2c6`, дальние
облака `#b4bdee`, чернила и контур `#1c2850`, искры на облаке `#c46a1e`, на небе — белые
`#fffaf0`. Ночное окошко (терминалы, YAML, код) — `#141d3d` в обеих схемах.

**Шрифты** (локально, латиница + кириллица, ~185 КБ): заголовки — Kurale
(`SkyMagic Display`, книжная сказочная антиква, одно начертание); текст и подписи —
Nunito 400–800 (`SkyMagic Text`); код — системный моноширинный.

**Фирменные детали.**
- Облачный берег (`--smg-bank-lg`, `--smg-bank-sm`) — сайдбар и шторка меню, герой
  «Главной» и «Старта», поле ввода чата и голосового режима, экран запуска.
- Четырёхлучевая искра (`--smg-spark`, clip-path) — единая отметка «активного»: пункт
  меню (едет с индикатором), выбранный собеседник, заголовки разделов, «онлайн»,
  «печатает» (три искры мерцают), отмеченный чекбокс, сегодняшний день, выбранная тема.
- Пузыри — облачка-реплики с хвостиком из двух «капель» (как у мысли в книжке): у
  персоны — контурное облако, у вас — сплошная капсула.
- Аватары — сплошные диски-«луны», цвет персоны — тонким кольцом.

**Живой фон** (`ambient.tsx`): чёткие точки и четырёхлучевые искры без ореолов, ≤ 76
знаков; яркость меняется очень медленно (6–14 с); искры обходят текст неба (шапка,
заголовки, герой) — гаснут и загораются в свободном месте. ≤ 20 кадр/с, пауза при
скрытой вкладке, reduced motion — статичный кадр.

**Что где.** `skin.css`: токены → небо и скроллбары → запуск → сайдбар → шапка →
заголовки и карточки → кнопки, бейджи, аватары, поля → вкладки, счётчики, модалки →
чат → все чаты → главная → «Старт» → комната → персоны → галерея → настройки, сервисы →
досье, режим управления, голос → телефон (≤ 760px). `swatch.css` — миниатюра.
